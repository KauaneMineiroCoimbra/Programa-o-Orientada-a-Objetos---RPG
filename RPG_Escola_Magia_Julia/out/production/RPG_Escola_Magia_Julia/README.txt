RPG ESCOLA ARCANA DE VALE-LUME
Criado por Julia

COMO EXECUTAR
1. Coloque todos os arquivos .java na mesma pasta.
2. Abra a pasta no IntelliJ, VS Code ou NetBeans.
3. Execute a classe Jogo.java.

IDEIA DO PROJETO
O jogador é um aprendiz de feiticeiro que chega à Escola Arcana de Vale-Lume.
O Professor Walter ensina quatro elementos, usando comandos simples:
>>  <<  ^^

O jogo possui:
- nome personalizado do jogador;
- nível de conhecimento mágico;
- vida;
- quatro magias;
- treino para aumentar os poderes;
- diálogos com 3 escolhas;
- livro sobre as pragas do jardim;
- cinco moradores para ajudar;
- conquistas com estrelas;
- batalha final contra Boots;
- possibilidade de tentar a batalha novamente sem perder o progresso;
- final com comemoração e mensagem de Julia.

O jogo foi mantido com conceitos de Java de nível iniciante:
classes, herança, atributos, métodos, if/else, while, for, Scanner,
objetos, polimorfismo simples e entrada do usuário.

DURAÇÃO
A duração é planejada para uma sessão de aproximadamente 30-40 minutos
dependendo da velocidade de leitura, escolhas e prática do jogador.
